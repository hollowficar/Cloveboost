## 📌 O que o projeto apresenta?

O CLOVEBOOST busca simular uma plataforma de serviços relacionados ao VALORANT, organizando as informações em diferentes páginas e proporcionando uma navegação simples.

<details>
<summary>🎯 <b>Apresentação do Elo Job</b></summary>

<br>

Página inicial dedicada à apresentação do serviço, explicando como funciona o processo de contratação e apresentando informações para os interessados.

</details>

<details>
<summary>📊 <b>Tabela de Preços</b></summary>

<br>

Uma seção dedicada à consulta dos valores por divisão, permitindo que o visitante visualize os preços e consulte as condições do serviço.

</details>

<details>
<summary>🛒 <b>Contratação de Elo Job</b></summary>

<br>

Página específica para apresentar o processo de contratação e facilitar o acesso às informações do serviço.

</details>

<details>
<summary>💎 <b>Loja de VP</b></summary>

<br>

Área dedicada à apresentação de pacotes de VALORANT Points (VP), organizando as opções disponíveis em uma interface própria.

</details>

<details>
<summary>
📱 <b>Interface e Identidade Visual</b>
</summary>

<br>

Design inspirado na estética de VALORANT, utilizando uma identidade visual própria, com tons escuros, detalhes em roxo e elementos em azul.

</details>

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** implementação de funcionalidades e interatividade.

## 🚀 Instruções de execução

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha feito o download ZIP.
3. Verifique se as pastas `css`, `js` e `imagens` estão presentes.
4. Abra o arquivo `index.html` em um navegador moderno.
5. Navegue pelas páginas para conhecer a interface do projeto.

## 📚 Objetivo do projeto

O desenvolvimento do CLOVEBOOST tem como objetivo colocar em prática conhecimentos de desenvolvimento Front-end, organização de arquivos, estruturação HTML, estilização CSS e lógica com JavaScript.

Também busca desenvolver habilidades de organização de projetos e utilização do GitHub como ferramenta de versionamento e apresentação de trabalhos.
